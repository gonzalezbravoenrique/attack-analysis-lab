# Lab - Análisis de ataques
## Objetivos
- Parte 1: investigar los IOC
- Parte 2: Investigar la actividad maliciosa
- Parte 3: Investigar la actividad más maliciosa

## Situación
Está trabajando como técnico cibernético y ha sido seleccionado para trabajar con el equipo de respuesta ante incidentes de XYZ, Inc. Un analista de ciberseguridad le ha pedido que evalúe los valores hash de las alertas de seguridad generadas por el Sistema de Prevención de Intrusiones (IPS). El IPS ha marcado una serie de eventos como potencialmente maliciosos.

Utilizará la herramienta en línea ANY.RUN y la matriz Mitre ATT & CK para realizar un análisis forense basado en los valores hash proporcionados.
